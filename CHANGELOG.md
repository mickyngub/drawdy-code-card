## 1.0.0

First public release

- paste or type code and place it on the board as a syntax-highlighted card image
- language picker with auto detect, from highlight.js's common languages
- seven themes: GitHub Light, GitHub Dark, One Dark, Dracula, Nord, Solarized Light and Monokai
- JetBrains Mono or Fira Code, font size, and ligatures on or off
- line numbers with a first line number, highlighted lines, and a window with three dots and a file name
- six gradient backgrounds, a solid colour or transparent, with padding, corner radius and shadow
- fit the card to the code, or set a fixed width in columns with soft wrap
- select a placed card to edit it in the panel and update it in place, keeping its spot, width, layer, frame, group, opacity and lock
- a new card lands beside existing content instead of on top of it, clear of the panel, and is selected; the board keeps its zoom
- style settings are remembered between sessions; the file name and highlighted lines are not, and nothing is saved while a card from the board is being edited
- click the preview to see it across the whole panel; Try a sample fills an empty panel
- the export scale reads rounded down, with a note when a long card comes out softer
- ⌘Z and Ctrl+Z undo on the board from the panel, Escape in a field leaves the field, and the panel follows the board theme while open
- storage and board permissions are asked when the panel first opens, not when the board loads
- a full board, a denied permission or a board that doesn't answer gets a clear message instead of a stuck button
