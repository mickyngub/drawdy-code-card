# Changelog

## 1.0.0

First public release

- paste or type code and place it on the board as a syntax-highlighted card image
- language picker with auto detect, from highlight.js's common languages
- seven themes: GitHub Light, GitHub Dark, One Dark, Dracula, Nord, Solarized Light and Monokai
- JetBrains Mono or Fira Code, font size, and ligatures on or off
- line numbers with a first line number, highlighted lines, and a window with three dots and a file name
- six gradient backgrounds, a solid colour or transparent, with padding, corner radius and shadow
- fit the card to the code, or set a fixed width in columns with soft wrap
- select a placed card to edit it in the panel and update it in place
- style settings are remembered between sessions
